# Release Notice

Tempoledger is the public release of a scheduler and backend the author wrote
in 2024-2025. It is published under the MIT license in LICENSE.

Changes made for this release include neutral package/event names, isolated
seeded RNG, explicit log-only agent results, provider opt-in gates, input
validation, JSON serialization and async migration URL corrections, independent
schedule audits, synthetic replay fixtures, fresh tests and rewritten
documentation. The heuristic's feasibility limitations are documented rather
than represented as solved. External services and third-party libraries are
not bundled.
